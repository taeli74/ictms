Easy ICT Master — 정보통신 유지보수 관리 (단독 실행 패키지)

[올리는 방법: GitHub Pages — taeli74.github.io/ictmaster]
1. 이 zip을 풀어 나온 파일(index.html, robots.txt, .nojekyll, README.txt)을
   저장소 taeli74/ictmaster 최상위에 올리고 Commit 합니다.
   (웹: Add file > Upload files. .nojekyll은 숨김 파일이라 안 보이면 없어도 됩니다.)
2. 저장소 Settings > Pages > Source: Deploy from a branch > main / (root) > Save.
3. 1~2분 뒤 https://taeli74.github.io/ictmaster 로 접속합니다.
   (기존 README.md는 지워도, 그대로 둬도 됩니다.)

[처음 사용]
- 아이디 admin / 비밀번호 12345 로 로그인 → 내 계정에서 바로 비밀번호를 바꾸세요.
- 설정에서 고객(발주처) → 점검 위치 → 점검업체 → 점검자를 등록하고 계정을 발급합니다.

[엑셀로 사이트 등록]
- 설정 > 엑셀로 사이트·위치 일괄 등록 > 양식 다운로드 → 작성 → 엑셀 업로드. (엑셀 라이브러리를 CDN에서 불러오므로 인터넷 연결 필요)

[꼭 알아둘 점]
- 서버가 없습니다. 모든 데이터와 사진은 접속한 기기의 브라우저에만 저장됩니다.
  기기·브라우저가 다르면 데이터가 공유되지 않습니다.
- 브라우저 데이터를 지우면 사라집니다. 내 계정 > 데이터 백업으로 정기 백업하세요.
- 로그인은 화면 구분용이며 보안 기능이 아닙니다. 실제 고객 정보를 여러 사람이
  함께 쓰려면 서버(DB·인증)가 필요합니다.
- Word(.docx) 출력은 인터넷 연결이 필요합니다(문서 라이브러리를 CDN에서 불러옵니다).
